# Тест-кейсы экрана «Создать пароль» (шаг 3)

## Принятые требования к паролю
- Минимальная длина: 8 символов
- Ограничения по составу (заглавные, цифры, спецсимволы): отсутствуют
- Максимальная длина: НЕ УТОЧНЕНО — вопрос аналитику
- Пробелы: не валидируется
- Кириллица: не валидируется
