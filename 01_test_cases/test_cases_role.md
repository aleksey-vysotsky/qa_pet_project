# Тест-кейсы экрана «Выбрать роль» (шаг 4)

## Принятые требования к экрану «Выбрать роль» (шаг 4)
- Количество ролей: 2 («Я тренер», вторая роль — «Я клиент»)
- Каждая карточка — единый кликабельный элемент: тап в любую зону карточки выбирает роль
- Плашки на карточках («Клиентская база», «Программы», «Календарь», «Биллинг»): информационные, не интерактивны
- Результат выбора: переход на следующий экран
- Выбор без роли: невозможен
- Системный Back: возврат на шаг 3 «Создать пароль»
- Скролл: весь контент экрана доступен прокруткой
- Повторный заход на экран: сохраняется предыдущие данные

### TC-ROLE001. Выбор роли «Я тренер» (позитивный сценарий)

| Поле | Содержание |
|---|---|
| **Предусловия** |  1. Пользователь запустил приложение<br>2. Прошёл шаг 1 «Регистрация» с валидным email<br>3. Прошёл шаг 2 «Проверка кода», введён валидный код<br>4. Открыт экран шага 3 «Создать пароль» введен валидный пароль <br> 5. Нажата кнопка «Создать аккаунт» <br> 6. Открыт экран «Выбор роли»  |
| **Шаги** | 1. Выполнить тап по карточке «Я тренер» (между заголовком и плашками)<br>2. Контролировать результат |
| **Тестовые данные** | - |
| **Ожидаемый результат** | Выполняется выбор роли «Тренер», переход на следующий экран тренера «Как к вам обращаться?» |
| **Статус** | Passed |
