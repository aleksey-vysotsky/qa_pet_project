# Тест-кейсы экрана регистрации

## Принятые требования к email
- Локальная часть: `[a-zA-Z0-9. + - _ %]`
- Доменная часть: `[a-zA-Z0-9]`
- Минимальная длина: 5 символов
- Максимальная длина: 254 символа (RFC 5321)

## Как вести статусы
- `Not run` — кейс ещё не прогнан на новой сборке
- `Passed` / `Failed` — локальная проверка без обращения к серверу
- `Blocked` — кейс нельзя выполнить (блокирует окружение/сервер)
