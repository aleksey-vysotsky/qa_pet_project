# Тест-кейсы экрана регистрации

## Принятые требования к коду
- Валидные значения: `[0-9]`
- Максимальная длина: 4 символа

## Сборка для прогонов
Новая сборка с рабочим бэкендом (версия: **0.1.26**).


### TC-CODE001. Ввод валидного кода

| Поле | Содержание |
|---|---|
| **Предусловия** |1. Пользователь запустил приложение<br>2. Кликнул кнопку «Создать аккаунт»<br>3. Открыт экран регистрации (шаг 1 из 3)<br>4. Введён валидный email, нажата кнопка «Продолжить»<br>5. Открыт экран шага 2 «Проверка кода», код отправлен на почту|
| **Шаги** | 1. Вводит валидный код (всплывает внизу экрана) <br>2. Контролирует переход на экран шага 3 «Создать пароль» |
| **Тестовые данные** | - |
| **Ожидаемый результат** | Выполняется переход на шаг 3 «Создать пароль» |
| **Статус** | Passed |
