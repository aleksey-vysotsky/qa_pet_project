# QA Pet Project: тестирование мобильного приложения
проект по тестированию приложения FitEra 0.1.36

## Структура
- `01_test_cases/` — тест-кейсы по экрану регистрации
- `02_bug_reports/` — баг-репорты со скриншотами

## Что тестируется
Экран регистрации (шаг 1 из 3): <br>
- Валидация email <br>
- Состояние кнопки «Продолжить» <br>
- Переход между экранами <br>

Экран проверки кода (шаг 2 из 3): <br>
- Валидация кода <br>
- Переход между экранами <br>

Экран создания пароля (шаг 3 из 3): <br>
- Валидация пароля <br>
- Состояние кнопки «Создать аккаунт» <br>
- Переход между экранами <br>

Экран выбора роли : <br>
- Работа тапа по карточкам ролей <br>
- Переход между экранами <br>

## Окружение
Android 16, эмулятор Pixel 1 (Android Studio Narwhal 4 Feature Drop)
