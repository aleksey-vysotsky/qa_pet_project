# QA Pet Project: тестирование мобильного приложения
проект по тестированию приложения FitEra

## Структура
- `01_test_cases/` — тест-кейсы по экрану регистрации
- `02_bug_reports/` — баг-репорты со скриншотами

## Что тестируется
Экран регистрации (шаг 1 из 3): валидация email, состояние кнопки «Продолжить», переход на шаг «Ввод пароля».

## Окружение
Android 16, эмулятор Pixel 1 (Android Studio Narwhal 4 Feature Drop)
